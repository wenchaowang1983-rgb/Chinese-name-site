# 做视频的提示词模板（"外企也打卡"）

用法：在装好本 skill 的 Claude Code 里，把下面整段粘进去，替换 `{{...}}` 的部分。想做系列就填多个视角，想只做一条就删到只剩一个。

````
使用 waiqi-daka-video skill，为"外企也打卡"做 {{N}} 条竖屏短视频，每条 ≤120 秒。

【主题与视角】
{{主题，例如：Elizabeth Holmes / Nike CEO 访谈 / 某场听证会}}
每条一个视角，面向有国际视野、尤其是在外企工作的中国职场人：
1. {{视角 1}}
2. {{视角 2}}
…
每条开头先抛一个职场问题；有热点就用一句话点出（{{热点，如"A24 新片《You Can See Everything》"}}）；适当穿插人物的传奇八卦。

【素材】
- 链接：{{YouTube / B站链接，可多个}}；也可以自己找近两年播放量高的访谈或纪录片补充。
- 下载（我已在本机 Chrome 登录）：
  COOKIES_FROM_BROWSER=chrome bash .claude/skills/waiqi-daka-video/scripts/fetch_video.sh <链接> work/<编号>
  读 Chrome cookie 失败就改 firefox，或用 COOKIES_FILE=cookies.txt。不要用任何绕过验证的办法。

【版式——不要改】
- 视频窗口占竖屏至少一半（现为 54%）；顶部品牌条只留一条细的（logo 小图标 + 小号"外企也打卡"字形 + 细红条）；下方只放紧凑的中文字幕。
- 字幕只写中文，不要英文。说话人用【警员】【长官】这类前缀，脚本会做成小标签。
- 品牌名必须用 logo 的原字体（assets/lettering_mask.png），配色用品牌绿/象牙白/金，不要荧光色、描边大字。
- 封面：人物/画面大图 + 一句不超过 14 字的原话金句，不加"真实事件""必看"之类杂项；封面必须用 1080p 以上的原片，裁掉电视台字幕条和台标。
- 人物不在画面正中时，用 focus_x（或片段里的 focus）调水平取景。

【结构】钩子（可选，3–7 秒最强原声）→ 开场动画 → 开篇旁白（先摆问题）→ 原声片段合计 45–60 秒（有对比：谁撒谎/谁认错/谁坚持）→ 结论金句 → 感谢收看淡出。
每条原声片段合计不超过约 1 分钟，其余用旁白——成片是评论，不是搬运。

【事实与措辞】
- 涉及判决、处分、金额、日期等的事实，先用至少两个来源核对再写；不确定的删掉，不要补。
- 分析性说法用"有分析认为"，传闻/细节用"据报道"，不要下定论、不要指控具体个人。
- 金句、标题必须忠于原话，不要比原话说得更满。
- 涉及未成年人、受害者的画面，不用正脸特写。

【版权】页脚注明素材来源；片段短、有评论。

【流程与确认】
1. 每条按 skill 里的步骤：下载 → 听写 → 读懂并核实 → 选片段 → 写旁白与中文字幕 → 写 config → 出片 → 抽帧自检。
2. **先只做第 1 条**，把成片和封面给我看，我确认后再做其余的。
3. 自检项：字幕是否越界、字幕与说话是否对齐、总长 ≤120 秒、音量（旁白与原声接近、结尾最后一秒近乎静音）。
4. 每条成片命名为"外企也打卡_编号_标题.mp4"，封面同名 _cover.png；中间文件放 work/ 下，不要提交到仓库。
5. 遇到下载/渲染报错，先按 skill 的"注意"部分排查；需要我做决定的（换来源、权限）直接问我。
````

## 在这个提示词里为什么这么写

- **先做一条再确认**：渲染一条约 4 分钟，版式或措辞不对，重做 4 条代价很大。
- **事实与措辞单独成段**：这类题材（真人、判决、丑闻）最容易在标题和结论里"说过头"。
- **版式写成"不要改"**：防止模型自己发挥，把已定的设计（窗口占比、品牌字体、只出中文）改回去。
