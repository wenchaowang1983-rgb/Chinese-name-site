# 做视频的提示词

skill 自己会选题、策划、判断、写脚本；版式、封面、字幕、品牌等规则都已写在 skill 里。**提示词只需要说：做什么、给了什么方向、有什么素材、有什么热点。**

## 最短写法

````
用 waiqi-daka-video skill 做 {{人物/事件/主题}} 系列，{{约 N 条}}。
方向：{{你的大致想法}}。你也可以找到更好的视角。
素材：{{链接}}，也可以自己找近两年高播放的访谈或纪录片。
我本机 Chrome 已登录 YouTube，下载用 COOKIES_FROM_BROWSER=chrome。
先给我选题方案，我确认后再做，并且先只做第 1 条给我看。其余你来判断。
````

## 例：Elizabeth Holmes 系列（已填好）

````
用 waiqi-daka-video skill 做 Elizabeth Holmes 系列，约 5 条。
读者是对国际视野感兴趣的中国人，尤其是外企人，要的是外企职场生存技能和跨文化视角：外企人怎么包装自己、怎么建立信任，那么多大佬都上当了、怎么避免被会包装的人欺骗，跨文化怎么看老外、怎么在老外面前展露自己。你也可以找到更好的视角。
穿插她的传奇八卦。最近关于她的纪录片（A24《You Can See Everything》）很火，要提一下。
素材：https://www.youtube.com/watch?v=BgNfrDXr7uA ，也可以自己找近两年点击量很高的访谈或纪录片。
我本机 Chrome 已登录 YouTube，下载用 COOKIES_FROM_BROWSER=chrome。
先给我选题方案，我确认后再做，并且先只做第 1 条给我看。其余你来判断。
````
