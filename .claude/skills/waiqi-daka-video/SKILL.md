# 外企也打卡 · 竖屏短视频

把一段真实视频（执法记录仪、听证会、演讲、访谈……）剪成 ≤120 秒、1080×1920 的竖屏视频，用一个职场问题串起来，最后落到一个观点上。
品牌：**外企也打卡**（Work & Wonder，"打卡外企如喝茶"）。logo 和字体已在 `assets/` 里。

## 成片结构（固定）

| 段落 | 时长 | 内容 |
|---|---|---|
| 钩子（可选，推荐） | 3–7 s | 采访里最震撼的一句原声（或最尖锐的提问），大字标题压在画面上 + 中文字幕；配置里写 `hook`。**有钩子时**封面不再占视频第 1 帧，只导出 `_cover.png` 供平台选封面 |
| 封面（无钩子时的第 1 帧） | 0.6 s | 见下方「封面」 |
| 开场动画 | 1.8 s | 封面渐变到品牌绿底 → logo 弹出 → logo 字体"外企也打卡"从左到右擦出 → 金线、标语；配"嗖 + 低音 + 两声叮" |
| 开篇 | 约 30 s | 先把问题摆出来（如"老板让你撒谎，你听不听？"），中文旁白 + 视频截图，交代背景 |
| 原声片段 | 约 55 s | 顶部缩小的品牌条，**视频窗口占竖屏 54%**，下方只放同步**中文字幕**（不放英文），说话人用小标签 |
| 结尾 | 约 25 s | 结果 + 结论金句（绿底卡片） |
| 感谢收看 | 约 3 s | 绿底 logo + "感谢收看"，旁白，画面与声音一起淡出 |

**总长必须 ≤ 120 秒**（脚本会告警）。超了就删原声片段，别压缩旁白语速。

## 封面（两种版式）

**默认用人物大图版**（`cover.style` 不写、或写 `"portrait"`；学「笔记侠」）：高清人物竖屏铺满、底部压暗渐变、标题为 **「人物/职位：最经典的一句话或问题」**（例：`Nike CEO：这不是工作，这是个人的事`）、右下角小 logo。
- 配置：`cover: {"who":"Nike CEO","quote":"金句","frame_time":240,"cover_source":"高清原片","focus_x":0.36,"crop_bottom":0.17}`。
- **必须用高清原片**做 `cover_source`（至少 1080p；720p 放大成竖屏会糊）。取人物正脸、有表情的一帧。
- `crop_bottom` 默认裁掉原片底部 17%，**去掉电视台字幕条/台标**，不要让别家台标出现在封面。
- 金句要短（≤ 14 字，两行内），必须是受访者原话的忠实意译，别加原话里没有的字（如"亲自""最"）。
- 想用「大标题 + 红条 + 画面」版式：写 `"style":"banner"`，并写 `line1/red/line2/size/crop_box`（`size` 按字数缩小，8 个字约 128）。
- **只改封面**不用重渲整条视频：`python3 scripts/build_video.py config.json --cover-only`。

## 封面要求清单（两种版式都适用，出封面前逐条过）

1. **标题是主角**：大字、一眼能读；人物版用「人物/职位：原话金句」，红条版用两行钩子问句（如"老板让你撒谎 / 你听不听？"，关键词标红）。
2. **画面来自视频本身**：取人物正脸、有表情或冲突感的一帧，**必须 1080p 以上原片**，720p 放大会糊。
3. **去掉别家标识**：用 `crop_bottom` / `crop` 裁掉电视台字幕条、台标、平台水印。
4. **金句 ≤14 字、忠于原话**：不比原话说得更满，不加原话里没有的字；涉及真人的指控性措辞一律用问句或原话。
5. **品牌只在底部/角落小而克制**：logo 图标 + logo 字体"外企也打卡"；**不加**"真实事件""必看""VS 对比框"等杂项；极简、商务、有奢感。
6. **涉及未成年人/受害者**：不用正脸特写。
7. **只改封面不重渲整条**：`python3 scripts/build_video.py config.json --cover-only`。
8. 有"钩子"时封面不占视频第 1 帧，只导出 `_cover.png`；无钩子时封面即视频第 1 帧（停 0.6 s 后渐变进开场动画）。

## 一个长视频拆多个主题

受众是外企白领，爱看：外企职场、高管视角、企业文化、管理、人才、晋升。拿到 5 分钟以上的长采访后，不要只做一条：
1. 通读转写，按主题切成 3–4 条（如：高管可及性/公私分明、老将回归与人才传承、战略迷失与重置、成本压力下的取舍）。
2. 每条一个 `config`、一个 `work_dir`，共用同一个 `source_video`；各自写 `hook`、`cover`、开篇、原声片段、结论。
3. 每条原声合计 20–45 s，其余用旁白——成片是评论，不是搬运原采访。
4. 每条的钩子取该主题最强的一句（可与正文原声重复），标题措辞不得比原话说得更满。
5. 逐条出片后抽帧检查，再统一交付。

## 流程

1. **环境**：`bash scripts/setup.sh`（装依赖、下载字体、可选装 YouTube 令牌服务）。需要出网：YouTube / googlevideo / ytimg / github / pypi / Google Fonts raw。
   云端会话若访问被拒（403 / 域名解析失败），是环境网络策略问题：让用户在环境设置里放开对应域名，**不要绕过**。
2. **取视频**：`bash scripts/fetch_video.sh <链接> <工作目录>` → `source.mp4`（+ `en.vtt` 自动字幕）。
   - YouTube 常见失败：`Sign in to confirm you're not a bot` 或流地址 403。脚本会自动换 `mweb / web_embedded / tv_simply` 客户端并用 bgutil 令牌服务；仍 403 说明云端 IP 被 YouTube 拒绝，**改找同事件的 B 站等副本**（B 站无需登录，`yt-dlp` 直接下）。B 站的版本往往带烧录中文字幕——用 `crop` 把底部裁掉。
   - 不要用任何绕过付费/登录/版权保护的手段。
3. **听写**：`python3 scripts/transcribe.py source.mp4 small en en.json`（要精确时间轴用 `medium`，只截关键片段跑）。
   - 输出每句起止秒和逐词时间戳，字幕时间轴以逐词时间为准，**句首句尾各留 0.1–0.2 s**。
   - Whisper 的 `small` 在嘈杂/重叠的对话里会乱编，关键句要听过或用 `medium` 复核，不确定的句子就别用。
4. **读懂视频、核实事实**：通读转写，找出"冲突点"和"各方选择"。结尾的结论里涉及结果（处分、判决、金额）的，要和视频或公开报道交叉核对，**不要只信一个来源的解说**；视频里的说法和事实有出入时，以事实为准并在脚本里改掉。
5. **选片段**：挑 3–4 组、合计约 55 秒的原声，要有对比（谁撒谎 / 谁认错 / 谁坚持）。每组配一个章节标签（"01 动手的警员：把电话推给长官"）。
6. **写脚本**（旁白 + 字幕）：
   - 开篇 5–6 句，每句 ≤ 25 字，口语化；第一句直接抛问题。
   - 字幕：**只写中文**，忠于原意的意译；**说话人用【警员】【爸爸】【长官】这种前缀**，脚本会自动做成小标签。英文原话只用于转写核对，不进画面（`en` 字段可省略；要显示英文才设 `show_english: true`）。
   - 结尾 3–4 句：结果 → 答案 → 一句可转发的金句。
7. **写配置**：复制 `examples/boulder.json` 改内容（字段见下）。
8. **出片**：`python3 scripts/build_video.py config.json`，约 4 分钟。输出 `成片.mp4` 和同名 `_cover.png`。
9. **自检**：抽几帧看（封面、开场、各章节、结尾），检查：字幕是否越界、是否与说话时间对齐、总长、音量（旁白与原声接近，结尾最后 1 秒应接近静音）。

## 配置字段（`examples/boulder.json` 为完整示例）

- `source_video` / `work_dir` / `output`：路径。
- `crop`（可选）：ffmpeg 预裁剪，去掉原片底部烧录字幕/水印，如 `crop=1280:590:0:0,delogo=x=18:y=16:w=260:h=46`。之后脚本会自动把画面裁成窗口比例（1080×1040，近似方形）。
- `focus_x`（默认 0.5）：水平取景中心，0 偏左、1 偏右；单个片段/静帧可在 `range` 或 `lines[]` 里写 `focus` 覆盖（人物不在画面正中时用）。
- `show_english`（默认 false）：为 true 才在字幕里显示 `en`。
- `hook`：`{tag, headline[2行], range:{start,end,subs:[{s,e,zh}]}}`——开头 3–7 秒原声钩子，格式同 `clips` 的 range。
- `cover`（旧版式字段）：`line1`（第一行大字）、`red`（第一行里要标红的字）、`line2`（第二行，绿色）、`frame_time`（取哪一秒的画面）、`crop_box`（该帧里要放大展示的区域 [x1,y1,x2,y2]，像素，相对 `crop` 之后的画面）。
- `intro.lines[]` / `outro.lines[]`：`{id, text, frame, headline[]}` 用视频静帧；或 `{id, text, card[2], card_sub}` 用绿底金句卡。`text` 同时是旁白和字幕。
- `clips[]`：`{tag, ranges:[{start,end,focus?,subs:[{s,e,zh}]}]}`，秒为单位（原视频时间）。
- `voice`（默认 `zh-CN-YunxiNeural`）、`rate`（默认 `+15%`）；`outro.thanks`、`outro.thanks_label`。

## 设计规范（改动前先读，别随意换）

- **版式**（1080×1920，**视频窗口必须占竖屏至少一半**）：顶部品牌条压到约 176px——**只放**居中的 logo 字体"外企也打卡"（宽 340，品牌绿）和下方一行小标语，**左上角不放 logo 图标**，细红条 y=164–176；章节标签在红条下（30px）；视频窗口 y=236，高 1040（54%），上下各 6px 绿边；中文字幕从 y≈1320 起（最多 3 行）；页脚小字 y≈1852。
- **颜色**：品牌绿 `#064937`，象牙白 `#F6F3EC`，墨色 `#0F1F1A`，金 `#C9A96A`，红条/强调红 `#E60012` / `#D1101F`。**不要用荧光黄、描边大字、爆炸贴纸等**——用户明确要"极简、商务、有奢感"，嫌"土"。
- **字体**：标题与金句 = 思源宋体 Black（Noto Serif SC 900）；中文字幕 = 思源黑体 Bold（62px，行距 84）；英文默认不显示（`show_english` 才用 Inter 40px）。品牌名**必须用 logo 里的原字体**——`assets/lettering_mask.png` 是从 logo 抠出的字形，用 `lettering(width, color)` 着色，**不要用别的字体手打**。
- **字幕**：只放中文，居中；两行时自动均分、优先在标点处断行；说话人是圆角小标签。字幕区要紧凑，把画面让给视频。
- **封面**：用人物大图版（见上），不加"真实事件""必看""VS"对比框等杂项。
- **声音**：旁白 +4 dB；原声片段首尾各 0.1 s 淡入淡出；整体 `loudnorm`（-15 LUFS）。开场/结尾提示音是脚本里用 ffmpeg 合成的，无版权问题。

## 注意

- **版权与隐私**：说明片段来源（页脚已有"真实执法记录仪画面·地点·日期"）；涉及未成年人、受害者时避免特写正脸，标题不下定论（用"听老板的还是忠于自己"这种问题式，不要指控具体个人）。
- **事实**：不要把不同来源的说法糅在一起；拿不准的细节就删，不要补。
- **性能**：`build_video.py` 逐段渲染，4 核约 4 分钟；中间产物在 `work_dir/out/`，改一个字幕重跑会全部重来（可接受）。
- **不要**把字体文件打进仓库（体积大，且 setup.sh 会下载）。
